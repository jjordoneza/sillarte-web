# Fotos de producto

Coloca aquí las fotos de cada pieza (recortes con fondo transparente o fotos
de producto normales, como las que ya llegaron para la Mesa Perla), con
estos nombres exactos:

- `mesa-perla.jpg` ✅ (ya está — foto principal)
- `banco-alto-calida.png`
- `silla-concha-camel.png`
- `silla-concha-gris.png`
- `silla-barril-negra.png`
- `silla-abanico-negra.png`

El formato no tiene que ser exactamente el del nombre (`.png` vs `.jpg`):
si llega en otro formato, se ajusta el nombre en `src/data/products.ts`
(campos `image`, `scene` y `galeria`) al subirla.
